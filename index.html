Ninput
Features Setup

Block your input with security.

Ninput is a powerful open-source utility for Windows that lets you instantly disable keyboard and mouse for cleaning, pets, or privacy.

Download Latest View Source Code

Total Lockdown

Completely disables mouse and keyboard inputs, preventing accidental commands and blocking Alt+Tab usage.

Custom Keybinds

Configure your own unique key combinations to activate or deactivate the block instantly.

Multi-Monitor

Full support for multi-monitor setups, ensuring that windows stay hidden and inputs remain blocked across all screens.

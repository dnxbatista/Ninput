# Ninput

A C# and WPF application designed to block keyboard and mouse inputs, perfect for cleaning peripherals or quick security locking.

## 🚀 Features
- Complete input blocking (keyboard and mouse).
- Protection against Alt+Tab and accidental closing.
- Customizable activation/deactivation shortcuts.
- Multi-monitor support.

## 🛠️ Technologies
- C# / .NET
- WPF (Windows Presentation Foundation)
- Win32 API (Low-level hooks)

## 📦 How to Use
1. Download the executable from the Releases tab.
2. Run the application and set your preferred keybinds.
3. Activate the block. To exit, use your configured shortcut.
